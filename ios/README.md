# Asympta World for iPhone

Native offline paper world. Build6 adopts the approved five halftone companions with translucent stipple auras on near-white lightly textured paper. No scenery or decorative collage. Bottom Home/Explore/Friends navigation preserves profile, favorites, journal, Aura, languages and movement. Existing version1 saves and resident IDs are unchanged. Pan/pinch still work; Explore restores the initial five-character composition.

See the canonical [native architecture](../docs/WORLD_RUNTIME_ARCHITECTURE.md#native-iphone-app-independent-of-web-runtime) and [historical build4/5 release record](../docs/IOS_SKETCH_RELEASE.md). Build6 source `5fec447c3512cd61499ae3bab96af3515a7b40b6` is signed/exported and available as TestFlight1.0(6), Apple build `418ebdc2-373f-4128-b4a3-36b50f299c86`, VALID/Internal. Official TestFlight1.0(6) was installed and the requested paper/character, interaction, navigation, Aura, language and lifecycle scenes verified on Dev iPad. Original personal data was byte-identical and ownership released. See [same-build evidence and limits](../docs/IOS_HALFTONE_RELEASE.md).

Generate with `xcodegen generate --spec ios/project.yml`, archive/sign AsymptaWorld for generic iOS, export using `ios/ExportOptions.plist`, then existing Internal TestFlight.
