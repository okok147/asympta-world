# Asympta World for iPhone

Build12 candidate extends the aura world with real selected nearby roads/important buildings in a sparse hand-pencil style and broad furry aura regions. Device location is requested in the foreground after an explanation; precise fixes stay local. Geographic mode shows the own approximate aura and actual connected nearby devices. Before location authorization, the explicit local simulation remains usable. Tap any visible aura for its ability history; pinch/drag explore and double-tap returns to your aura. No exact-position ring is shown.

Cloudflare service `asympta-world-aura` provides map caching, hibernating neighborhood presence and per-installation durable ability growth. A random Keychain capability authenticates only that installation. Growth is cached separately from unchanged personal version1 data. Existing journals/favorites/language/Aura/movement are preserved. This is not an account system; local simulated activities are not claimed as observed real-life work.
