# City-scale design reference

Active product direction: use the user's original dense urban map reference as the visual source of truth.

- The map itself is the primary UI.
- White / paper base, dense fine street network, bold dark arterial roads, restrained purple transit/rivers, sparse saturated land-use blocks.
- No large circular dashboard nodes, no generated infographic aesthetic, no enterprise control-room chrome.
- Locations are small typographic map labels only.
- Personal agents visibly travel to businesses; business-side agents then communicate, confirm orders, merchandise, source, produce, inspect, fulfil and deliver through the same city.
- Movement and handoffs must come from the canonical deterministic world state used by WebMCP.
- Human approval remains required before consequential payment/dispatch actions.
